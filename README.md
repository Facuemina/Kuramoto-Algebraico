# Kuramoto-Algebraico
Simulación y análisis espectral del modelo de Kuramoto con retardos temporales. Implementa el marco analítico complejo de Budzinski et al. (2023) [DOI: 10.1103/PhysRevResearch.5.013159] utilizando integración RK4 y descomposición de Galerkin vía FFT para predecir la emergencia de ondas espaciotemporales.
